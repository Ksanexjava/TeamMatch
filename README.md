# TeamMatch

Бот в MAX для поиска сокомандников на хакатоны, кейс-чемпионаты и олимпиады.

## Команда
- Роман (RomanRibakFR) — бэкенд, инфраструктура
- Миша (Ksanexjava) — логика подбора, лента, мэтчи

## Основной сценарий
1. `/start` → согласие на обработку данных.
2. Анкета: имя, фото, вуз, курс, город, роль, что ищет (хакатон / кейс-чемпионат / олимпиада / стартап), интересы, о себе, GitHub, контакт.
3. Лента анкет, отсортированная по совместимости → лайк / лайк с сообщением / пропуск.
4. Взаимный лайк = мэтч → оба получают карточку и контакт друг друга.

## Запуск через Docker (так же запускается на сервере)
```bash
cp .env.example .env        # вписать MAX_BOT_TOKEN
docker compose up --build -d
docker compose logs -f bot  # смотреть логи; выход — Ctrl+C
```
Остановить: `docker compose down`. Остановить и удалить базу: `docker compose down -v`.

## Запуск без Docker (для разработки)
Нужен Python 3.12. База — локальный файл SQLite, состояния анкеты — в памяти.
```bash
python -m venv .venv
source .venv/Scripts/activate   # Windows (Git Bash); на macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # вписать токен СВОЕГО тестового бота
python -m bot.main
```
Тесты: `python -m pytest -q`. Демо логики подбора без бота: `python demo.py`.

## Пошаговая проверка (для проверяющих)
Пройти основной сценарий и получить мэтч можно **в одиночку** — лента наполнена тестовыми анкетами, которые лайкают в ответ автоматически.

1. Открыть бота в MAX и нажать «Начать» (или отправить `/start`).
2. Нажать «Согласен(на), начнём».
3. Заполнить анкету: имя → фото (или «Пропустить») → вуз → курс (кнопка) → город → роль (кнопка) → что ищешь (кнопка) → интересы через запятую (например `python, ml, аналитика`) → о себе → GitHub → контакт. Нажать «✅ Сохранить».
4. В меню выбрать «🔍 Искать сокомандников» — появится анкета, отсортированная по совместимости, со строкой «⚡ почему подходит».
5. Нажать «👍 Лайк» — сразу придёт «🎉 У вас мэтч!» с карточкой и контактом собеседника (тестовая анкета лайкает в ответ автоматически).
6. Открыть «🤝 Мои мэтчи» — там будет этот мэтч с контактом.
7. Дополнительно: «💬 Лайк + сообщение» (бот попросит текст) и «👎 Пропустить» (анкета уходит из ленты).
8. «👤 Моя анкета» → можно скрыть анкету из поиска или удалить все свои данные.

**Ожидаемый результат:** после шага 5 приходит сообщение о мэтче с контактом, и этот мэтч виден в «Мои мэтчи».

## Переменные окружения
| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `MAX_BOT_TOKEN` | токен бота MAX | — (обязательно) |
| `DATABASE_URL` | адрес базы | SQLite `local.db`; в Docker — Postgres |
| `REDIS_URL` | Redis для шагов анкеты | пусто = память; в Docker — Redis |
| `LOG_LEVEL` | уровень логов | `INFO` |
| `SEED_TEST_PROFILES` | загрузить тестовые анкеты | `1` |

Порты наружу не открываются: бот получает сообщения через long polling.

## Структура
```
bot/            всё, что знает про MAX
  main.py       точка входа: python -m bot.main
  handlers/     start (меню, согласие), profile (анкета), feed (лента и мэтчи), fallback
  keyboards.py  кнопки
  texts.py      тексты и карточка анкеты
  states.py     шаги анкеты
core/           логика без MAX и без базы
  matching.py, recommendations.py, interactions.py   подбор, лента, мэтчи
  interests.py  нормализация интересов
db/             база данных: models.py (таблицы), repo.py (запросы), session.py (подключение)
data/           test_profiles.json — 40 ТЕСТОВЫХ анкет (сгенерированы, не реальные люди)
tests/          автотесты
```

## Данные
- Тестовые анкеты из `data/test_profiles.json` сгенерированы скриптом `tools/generate_test_profiles.py` и помечены в базе `is_test=True`.
- Контакт пользователя виден только при взаимном лайке. Пользователь может скрыть анкету или удалить все свои данные из бота.

## Известные ограничения
- Подбор простой и прозрачный: по общим интересам, городу, цели и взаимодополняющим ролям; без ИИ, учёта опыта и расписания.
- Тестовые анкеты (`is_test=True`) лайкают в ответ автоматически — только для демонстрации мэтча в одиночку; на реальных пользователях этого нет.
- Уведомление о лайке/мэтче доходит до человека, только если он хотя бы раз открывал бота (иначе бот не может ему написать первым).
- Лента загружает все активные анкеты в память — этого достаточно для MVP (сотни анкет); при масштабировании нужен отбор на стороне SQL.
- Анкета заполняется линейно, шага «назад» нет — при ошибке можно заполнить заново («✏️ Заполнить заново»).
- Модерации содержимого анкет пока нет.
- Данные — тестовые и введённые пользователями; реальной интеграции с вузами и внешними системами нет (следующий этап).
