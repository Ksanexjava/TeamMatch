# Mate-бот

Бот в MAX для поиска сокомандников на хакатоны, кейс-чемпионаты и олимпиады и другие мероприятия где необходимо участие в команде.

## Назначение решения
Mate-бот помогает студентам находить сокомандников на хакатоны, кейс-чемпионаты, олимпиады и другие виды активности с командным участием. Проблема простая: желание участвовать есть, а собрать команду тяжело, так как не все из знакомых заинтересованы в участие. Бот собирает анкеты студентов в одном месте и подбирает подходящих по интересам, роли и цели.

# Основной пользовательский сценарий;
1. Пользователь открывает бота, нажимает "Начать" или `/start`, что даёт Ваше согласие на обработку данных.
2. Заполняет анкету (фото, имя, вуз и прочее)
3. Пользователь Листает ленту анкет, отсортированную по совместимости. Под карточкой три кнопки: Лайк, Лайк с сообщением или Пропустить.
4. При взаимном лайке пользователи получают контакты друг друга, чтобы организовать дальнейшее общение.

## Состав и архитектуру решения;
Проект написан на Python и разделен по папкам и слоям, чтобы можно было легко понимать логику проекта.
- папка "bot", в ней лежит всё, что связано с MAX: `main.py`, `handlers/`, `keyboards.py`, `texts.py`, `states.py`, `media.py`.
- папка "core", в ней лежит логика работы: как считать совместимость, как работает лента, лайки/метчи и д.р.
- папка "data", содержит 40 тестовых анкет.
- папка "db", отвечает за подключение, создание таблиц, загрузка тестовых анкет

## Внешние сервисы и интеграции
- MAX Bot API — основная интеграция
- PostgreSQL — хранение анкет и свайпов.
- Redis — хранение состояний заполнения анкеты (FSM).

## Описание работы с данными
- Анкеты и свайпы хранятся в базе. Интересы приводятся к единому виду (нижний регистр, синонимы).
- Контакт пользователя виден только при взаимном лайке. Пользователь может скрыть анкету или удалить все свои данные из бота.

## Порядок работы с тестовыми данными? пошаговый сценарий проверки
 В `data/test_profiles.json` лежат 40 тестовых анкет (сгенерированы `tools/generate_test_profiles.py`).
- При первом запуске они автоматически загружаются в базу (если `SEED_TEST_PROFILES=1`) и
  помечаются `is_test=True` — это не реальные люди.
- Тестовые анкеты лайкают в ответ автоматически, чтобы проверяющий мог получить мэтч
  в одиночку (живых пользователей на проверке ещё нет).

## Пошаговый сценарий проверки
1. Открыть бота в MAX, нажать «Начать».
2. Согласиться на обработку данных.
3. Заполнить анкету (фото можно пропустить).
4. Нажать «🔍 Искать сокомандников» — появятся тестовые анкеты с сортировкой и строкой «⚡ почему подходит».
5. Нажать «👍 Лайк» на любой — сразу придёт «🎉 У вас мэтч!» с контактом (тестовая анкета лайкает в ответ).
6. Открыть «🤝 Мои мэтчи» — там будет этот мэтч.

## Примеры ожидаемого поведения системы
- Лайк тестовой анкеты → «🎉 У вас мэтч!» с карточкой и контактом.
- Пропуск (👎) → карточка остаётся в чате как инфо (без кнопок), снизу появляется следующая анкета.
- Лента отсортирована: чем больше общих интересов (+ один город, + одна цель), тем выше анкета.
- Если в анкете мат или реклама — бот не примет и попросит переписать.

## Известные ограничения
- Подбор простой и прозрачный: по общим интересам, городу, цели и взаимодополняющим ролям; без ИИ, учёта опыта и расписания.
- Тестовые анкеты (`is_test=True`) лайкают в ответ автоматически — только для демонстрации мэтча в одиночку; на реальных пользователях этого нет.
- Уведомление о лайке/мэтче доходит до человека, только если он хотя бы раз открывал бота (иначе бот не может ему написать первым).
- Анкета заполняется линейно, шага «назад» нет — при ошибке можно заполнить заново («✏️ Заполнить заново»).
- Сделана автоматическая модерация анкет (пулл бан-вордов)
